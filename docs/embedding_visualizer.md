# 3D pgvector Embedding Visualizer

This module provides a beautiful, interactive 3D dashboard for visualizing high-dimensional property description embeddings (768-dimension vectors generated by models like `sentence-transformers`) stored in PostgreSQL using the `pgvector` extension. 

By applying dimensionality reduction algorithms, it projects the 768-dimensional semantic vectors into a 3D coordinate space, allowing you to visually explore how properties cluster based on their descriptions.

---

## 🛠️ Technology Stack & Architecture

The visualizer utilizes a modern data-science and visualization stack:
1. **Data Source**: PostgreSQL `properties` table with `pgvector` columns (`description_vector`).
2. **Backend/Processing Script** (`scripts/visualize_embeddings.py`):
   - **Psycopg2**: Connects to the database and fetches the data.
   - **NumPy / Pandas**: Handles data manipulation.
   - **Scikit-learn (PCA & t-SNE)**: Performs multi-dimensional scaling and reduction to 3 dimensions.
   - **Python Webbrowser**: Launches the generated visualization in the user's default browser.
3. **Frontend Dashboard** (`real_estate_embeddings_3d.html`):
   - **HTML5 / CSS3**: Structured with custom CSS implementing a dark-themed glassmorphism aesthetic.
   - **Plotly.js (v2.24.1)**: Powers the interactive WebGL-accelerated 3D scatter plots.
   - **Google Fonts**: Uses the premium *Outfit* font family.

## 🧬 Dimensionality Reduction Methods

Because human eyes cannot perceive 768 dimensions, the visualizer uses two complementary algorithms to project vectors to a 3D space:

### 1. Principal Component Analysis (PCA)
* **What it does**: A linear method that identifies the orthogonal directions (principal components) along which the variance of the data is maximized.
* **Best for**: Preserving the global structure, distance relationships, and variance of the dataset.
* **Performance**: Fast and deterministic.

### 2. t-Distributed Stochastic Neighbor Embedding (t-SNE)
* **What it does**: A non-linear, probabilistic method that maps high-dimensional points to 3D coordinates such that similar points are modeled by close 3D coordinates and distant ones by distant ones.
* **Best for**: Visualizing localized semantic clusters (e.g., grouping all beach villas, compact studios, or medina houses close together).
* **Performance**: Iterative and highly structured for clustering.

## 🎨 Dashboard Features

The generated dashboard contains several advanced capabilities:

* **Dark-Themed Glassmorphism UI**: Beautiful, modern dark UI using blur backdrops, vibrant gradients, and premium typography.
* **Interactive 3D Viewport**: Left-click to orbit, right-click to pan, scroll to zoom. Clicking points displays detailed information.
* **Projection Toggling**: Instant tabs to switch between PCA and t-SNE projections.
* **Interactive Filter & Search**: 
  - Search properties by title or city using the live search box (matching nodes automatically glow/scale up).
  - Filter by property type (Villas, Apartments, Houses, Studios) or listing type (Sale, Rent).
* **Detailed Sidebar**: Lists all properties with coordinates, type, price, and dimensions.
* **Summary Metrics**: Displays active property counters, PCA explained variance, and t-SNE perplexity values.

## 🚀 How to Run the Visualizer

The script is located in `scripts/visualize_embeddings.py` and can be run using standard Python.

### Mode A: Real Database Mode (Default)
To visualize embeddings stored in your actual database:
1. Ensure your PostgreSQL database is running (e.g., via Docker).
2. Seed the database with embeddings:
   ```bash
   docker exec -it FastAPI_backend python seed.py
   ```
3. Run the visualizer:
   ```bash
   python scripts/visualize_embeddings.py
   ```

### Mode B: Demo Mode (Automatic Fallback)
If the script cannot connect to PostgreSQL or finds an empty database, it **automatically falls back** to Demo Mode. 
In Demo Mode, the script:
1. Generates **45 synthetic properties** across 4 property categories (Villas, Apartments, Houses, Studios) and 2 listing types (Sale, Rent).
2. Generates **synthetic 768D embeddings** with class-specific offsets to simulate realistic semantic clusters.
3. Runs PCA & t-SNE and launches the visualizer.

To explicitly force Demo Mode at any time, run:
```bash
python scripts/visualize_embeddings.py --demo
```
