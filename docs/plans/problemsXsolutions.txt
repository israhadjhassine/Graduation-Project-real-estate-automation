-Why Using One Client ID Can Be Problematic

If both use the same Client ID:

All redirect URIs must be added to one OAuth config

Harder to debug redirect mismatch errors

If you change something for one app, it may break the other

If you deploy one app, you must update the same client again

Security becomes less isolated


The AI is "hallucinating" the IDs because, while the backend sends the correct ID in the JSON data (rag_properties), the Readable Context String (which the AI actually reads to understand the property) does not currently contain the ID.

The AI sees:

"Property 1: Ocean Breeze Mansion..."
(Where is the ID? It's hidden in the JSON part it ignores).

And it guesses: "I'll use ID 234."
