1. List all tables
docker exec -it real_estate_db psql -U postgres -d real_estate -c "\dt"

2. See the structure of a table (e.g., the userstable)
docker exec -it real_estate_db psql -U postgres -d real_estate -c "\d users"

3. Check your Agents info
docker exec -it real_estate_db psql -U postgres -d real_estate -c "SELECT id, full_name, email FROM users WHERE role = 'agent';"

4. Check the latest Properties and their assigned Agents

docker exec -it real_estate_db psql -U postgres -d real_estate -c "SELECT id, title, city, agent_id FROM properties LIMIT 10;"

5. Enter the interactive database shell (most flexible)
If you want to run many queries, just enter the shell directly:

docker exec -it real_estate_db psql -U postgres -d real_estate
